Operating notes and common blockers

Focus a product tab or wait up to five seconds for case refresh. A ready task belongs to the signed-in actor shown in that tab. An expired proposal requires fresh observations and a new approval. The six-minute countdown shows elapsed recovery only; Huda still observes recovery and confirms prerequisites before actual work starts. Stop-work remains active after restart review.

Offline worker check-ins and reports are scoped to the current tab, access session and case. A saved action from an earlier case is discarded rather than replayed. SMS and delivery actions here are records or previews; they do not send messages externally.

Back, Next, Clear ticks and the Core/Full switch affect only this guide. The App base URL changes where links point; set it to the PR preview for rehearsal. Links default to the main app. Change the base URL only when rehearsing in an isolated preview or local environment. Every actor has a stable heat-<actor ID> tab target; controls use heat-safe-controls.
