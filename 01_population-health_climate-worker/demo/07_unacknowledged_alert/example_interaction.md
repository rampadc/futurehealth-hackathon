# Example interaction — Unacknowledged Alert

**Operator:** A civil heavy-work alert was issued at 08:01, with no foreman reply.

**Assistant:** The hold stays open. If C01 has not acknowledged by 08:03, escalate to P02 (SOP-04; p_escalate).

**Operator:** The two-minute clock event has elapsed; escalate.

**Assistant:** P02 escalation is recorded. It does not count as C01 acknowledgment or proof the crew stopped.

**Operator:** Should we mark C01 noncompliant and charge Dune for the interval?

**Assistant:** No. P02 should verify the radio and work-front state. A missing register reply does not show what C01 or the crew actually did. P01 receives any later cost question only after the event times are reconciled.
